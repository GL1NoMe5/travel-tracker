# Переработка интерфейса для казуальных пользователей

Направление зафиксировано 2026-11-09 по запросу пользователя: полностью заменить интерфейс, убрать JSON-экспорт и функции, перегружающие повседневный сценарий. Продуктовые ограничения описаны в `PRODUCT.md`, визуальные решения — в `DESIGN.md`.

## Что мешало в прежнем экране

| Наблюдение | Решение |
| --- | --- |
| Мятные градиенты, стеклянные поверхности и тени привлекали внимание к оболочке | Нейтральная светлая оболочка; цвет и детализация сосредоточены в настоящей карте |
| Каталог, статистика, режимы и редактор одновременно занимали большую часть экрана | Одна контекстная панель по действию пользователя |
| Два поисковых поля требовали заранее решить, какой инструмент нужен | Общий поиск страны или города |
| JSON, импорт, ручные координаты и HEX-коды предъявляли технические действия обычному пользователю | Удаление этих элементов из интерфейса |
| Страна требовала выбрать цвет, прежде чем считалась посещённой | Прямое действие «Я здесь был» |
| Подробные повторные визиты и служебные подписи перегружали простое сохранение места | Название, необязательная дата и заметка; старая история доступна по необходимости |
| Процент, прогресс и «из 195» повторяли статистику и делали экран похожим на отчёт | Компактные сведения в коллекции, открываемой через «Мои места» |

## Что остаётся

Карта, поиск, отметки стран и мест, редактирование воспоминаний, удаление отметки и автоматическое сохранение. Упрощение интерфейса не меняет ключ хранилища, схему записей или уже сохранённые цвета, даты и визиты. Удаление UI импорта/экспорта не означает удаление функций внутренней сериализации и валидации.

Nominatim не используется для автоматических сетевых запросов на каждый введённый символ. После явной отправки поиска сохраняются очередь, кэш и ограничения частоты. Ошибки сети допускают ручное название точки; ошибки хранилища должны объяснять состояние и давать возможность повторить сохранение.

## Локальный шрифт

[Manrope](https://github.com/google/fonts/tree/b31870aff700ab7a1d74fa0c6887d95beb9e0037/ofl/manrope) получен из официального репозитория Google Fonts, commit `b31870aff700ab7a1d74fa0c6887d95beb9e0037`. Автор, указанный в метаданных: Mikhail Sharanda; правообладатель — The Manrope Project Authors. Лицензия — SIL Open Font License 1.1.

- `public/fonts/Manrope-Variable.ttf` — 164 700 байт, ось `wght` 200–800.
- `public/fonts/Manrope-OFL.txt` — полный текст лицензии.
- `public/fonts/Manrope-METADATA.pb` — исходные метаданные Google Fonts.
- SHA-256 файла шрифта: `3ae11c49db0455a3cc33e37d380f20fdb8c7f8b41dc07625c177e3d87a9d6ae6`.

Проверены формат TrueType, наличие таблицы переменного шрифта `fvar` и диапазон русской кириллицы А–я, включая Ё/ё, в таблице `cmap`. Шрифт обслуживается приложением локально по `/fonts/Manrope-Variable.ttf`, без обращения браузера к Google Fonts.
