# Геокодирование

`createGeocoder()` из `src/services/geocoder/index.ts` предоставляет `searchCities(query, signal?)` и `reverseGeocode([longitude, latitude], signal?)`. Создание клиента не отправляет запросов. UI вызывает методы только после Enter/кнопки поиска либо явного клика по карте. Не подключать поиск к вводу текста.

Настройка `geocoding.baseUrl` загружается из `public/config.json` при первом обращении. После смены URL достаточно обновить страницу; пересборка приложения не нужна. Провайдер должен поддерживать Nominatim API, CORS и HTTPS (HTTP разрешён для localhost). При размещении в подпапке используется Vite BASE_URL.

Публичный Nominatim запрещает autocomplete и ограничивает суммарный поток приложения одним запросом в секунду: https://operations.osmfoundation.org/policies/nominatim/. Эта архитектура предназначена для одного пользователя с вкладками одного origin. Для публичного сервиса или нескольких устройств необходим общий серверный лимитер/кэш либо другой провайдер. Не удалять атрибуцию OpenStreetMap. Браузер отправляет Referer с origin приложения; User-Agent вручную не подменяется. Даты и заметки в запросы не включаются.

Поиск и reverse делят очередь и Web Lock. После получения блокировки каждый новый запрос ждёт минимум 1100 мс до отправки, даже если это первый запрос вкладки. Блокировка удерживается во время запроса. Это сохраняет интервал при отмене и закрытии предыдущей вкладки, в том числе когда чтение localStorage работает, а запись заблокирована квотой. Общий timestamp хранится отдельно от путешествий и позволяет учитывать дополнительное ограничение после перезагрузки. Когда localStorage недоступен, работа продолжается с памятью и той же безопасной паузой. Без Web Locks поиск безопасно отключается с объяснением; ручное создание отметки остаётся доступным. Не заменять это ограничителем только внутри одной вкладки.

Кэш ограничен 150 записями и 30 днями, хранится в отдельном ключе и не включается в пользовательский экспорт. Ошибки storage не блокируют интерфейс. Запрос завершается по таймауту через 12 секунд. Ответ 429 сохраняет Retry-After (по умолчанию 60 секунд), автоматических повторов нет. Ошибки `GeocoderError` содержат `code`, русское `message` и при ограничении `retryAt`. Отмена имеет стандартный `AbortError`, её не нужно показывать как ошибку пользователю. UI дополнительно должен проверять идентичность текущего черновика: ответ не должен перезаписывать ручной ввод.

Поиск ограничен населёнными пунктами (`featureType=city`), обратный запрос использует `zoom=10`. Сервис сохраняет координаты клика, поскольку reverse возвращает ближайший подходящий объект. Если населённый пункт не определён, UI предлагает ручной ввод. Идентичность результата — `osm_type:osm_id`, а не `place_id`; поиск и reverse могут вернуть разные объекты одного города, поэтому сопоставление с сохранёнными городами выполняется отдельным доменным модулем.

Документация: https://nominatim.org/release-docs/latest/api/Search/ и https://nominatim.org/release-docs/latest/api/Reverse/.
