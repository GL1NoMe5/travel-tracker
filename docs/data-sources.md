# Географические данные

## Каталог стран

`src/data/country-codes.json` фиксирует продуктовый каталог из 195 ISO alpha-2 кодов: [193 государства — члена ООН](https://www.un.org/about-us), [Святой Престол и Палестина](https://research.un.org/en/unmembers/observers). Количество объектов исходного GeoJSON не используется как знаменатель статистики. Зависимые территории и другие области вне каталога видны на базовой карте, но не получают отдельную отметку посещённой страны.

Русские названия определяются через `Intl.DisplayNames(['ru'], { type: 'region' })`. Данные хранятся по ISO-коду, а не по переведённому названию.

## Границы

- Источник: [datasets/geo-countries](https://github.com/datasets/geo-countries), производный от Natural Earth Admin 0 в масштабе 1:10m.
- Закреплённый commit: `ca3b7150caa5d3cc3fb108a87fc6e3d57bd97d99`.
- [Исходный GeoJSON](https://raw.githubusercontent.com/datasets/geo-countries/ca3b7150caa5d3cc3fb108a87fc6e3d57bd97d99/data/countries.geojson).
- SHA-256 исходника: `392a03db8aa3ba82c105852655620129b11182b95dfc34ef046827ea7d0e5b8c`.
- Геометрия Natural Earth находится в [общественном достоянии](https://www.naturalearthdata.com/about/terms-of-use/).
- Natural Earth описывает границы преимущественно de facto. Приложение не редактирует их самостоятельно; набор не предназначен для определения юридического статуса территорий.

Приложение загружает только локальный `public/data/countries.geojson`: 195 объектов `MultiPolygon`. `feature.id` и `properties.iso2` равны ISO-коду. Полигоны одного государства объединены под одним ID, поэтому его части закрашиваются вместе. Исходные вершины, внутренние кольца и разрезы по антимеридиану сохранены. Франция и Норвегия имеют корректные коды; специальные значения вроде `-99` не используются как ID.

Файл занимает приблизительно 11,14 MB без транспортного сжатия. На первом этапе удалены ненужные свойства и пробелы; геометрическое упрощение не выполняется, чтобы сохранить микрогосударства, острова и согласованные границы. Геометрия передаётся MapLibre как URL одного источника; её не следует импортировать в JS-бандл или загружать заново при каждом изменении цвета. При последующем хостинге рекомендуется включить gzip/Brotli на статических ресурсах.

## Камера

`src/data/country-geography.json` содержит воспроизводимо вычисленные координаты и zoom. Точка располагается внутри крупнейшей части страны, а масштаб учитывает близкие части. Для США и Норвегии масштаб привязан к основной материковой части: Аляска/Алеутские острова и Шпицберген иначе дают почти глобальный охват. Геометрия этих частей при этом полностью сохранена. Долготы для расчёта масштаба разворачиваются относительно точки, поэтому Фиджи не центрируется на Гринвиче. Отдалённые заморские части не заставляют камеру смотреть в середину океана. Это представительский вид страны, а не обещание уместить каждую отдалённую территорию в любой viewport.

## Воспроизведение и проверка

Выполнить из корня проекта:

```sh
node scripts/prepare-countries.mjs
npm test -- src/data/countries.test.ts
```

Скрипт загружает только закреплённый исходник, проверяет SHA-256 и использует локальный `.cache/geodata` при повторном запуске. После подготовки обновляются GeoJSON, каталог камер и `countries.manifest.json`; дата запуска намеренно не добавляется, чтобы файлы воспроизводились побайтно. Скрипт завершается ошибкой, если отсутствует хотя бы одна из 195 стран, кольцо незамкнуто или ребро пересекает антимеридиан без разреза.

Тесты дополнительно проверяют малые государства, русские названия FR/NO, центры на суше, multipart-геометрию и целостность итогового файла.
