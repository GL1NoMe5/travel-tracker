# Проверка нового интерфейса — 9 ноября 2026

Интерфейс полностью переработан по запросу пользователя. Главный экран — карта и действия «Добавить место» / «Мои места». Поиск, коллекция и редактор открываются в одной панели; на телефоне — в нижней шторке. JSON-инструменты, поля координат, палитра, постоянный переключатель режимов и подробная статистика удалены.

Сохранённые данные совместимы: ключ `travel-tracker:data:v1` и схема версии 1 не менялись. Старые цвета, OSM-алиасы, даты и все визиты сохраняются. Исходники и навыки Unslop / Impeccable загружены и применены; версии, лицензии и решения — [ui-redesign.md](ui-redesign.md). Argon для этой переработки не вызывался.

## Проверенные сценарии

- Страна: поиск или клик, «Я здесь был», удаление отметки и восстановление после перезагрузки.
- Место: поиск только по отправке формы, выбор точки на карте, ручное название при ошибке reverse, дата и заметка, сохранение и удаление.
- Старые данные: несколько визитов остаются у одного флажка; предыдущие даты и заметки доступны в истории.
- Неоднозначные совпадения: объединение либо отдельное место, корректное владение OSM-алиасами.
- Асинхронность: поздний reverse не переписывает ручной текст; save/delete блокируются на время Web Lock; закрытие защищает несохранённые изменения.
- Хранилище: конфликт вкладок, отказ квоты и повтор сохранения актуального снимка, повреждённая строка не перезаписывается при загрузке.
- Восстановление: подтверждённое «Начать заново» сначала сохраняет точную исходную строку под отдельным recovery-ключом; при отказе копирования исходные данные остаются нетронутыми.
- Карта: проекция, русские подписи, порядок слоёв, заливка под дорогами, микрогосударства и сложные страны, маркеры за глобусом, клики вне сферы, drag/pan/pinch.
- Сбои карты: загрузка границ, ошибки стиля/TileJSON/GeoJSON, отсутствие WebGL2 и потеря контекста, повторная загрузка.
- Интерфейс: одна открытая панель, отсутствие удалённых инструментов, Tab/стрелки/Escape, возврат фокуса, сохранение одного canvas при resize, размеры телефона/десктопа и промежуточные ширины.

## Дефекты, найденные при независимой проверке

1. При ширине 761 px старое ограничение правого отступа оставляло часть кнопок карты под длинной панелью. Теперь учитывается её фактический размер. Проверяются края и углы кнопок при 761×600, а не только их центр.
2. На телефоне быстрое нажатие «Я здесь был» увеличивало высоту шторки и прерывало перелёт к стране. Карта теперь продолжает активный программный перелёт с новыми отступами; пользовательский жест и закрытие редактора отменяют цель. Новый тест воспроизвёл ошибку на старой сборке и проходит после исправления.
3. Кнопка сохранения в мобильном редакторе могла уходить ниже видимой области. Теперь она закреплена внутри прокручиваемой формы.
4. После удаления технических инструментов повреждённое хранилище лишалось пути продолжения. Добавлено только контекстное подтверждённое восстановление с предварительной локальной копией; обычный экран не получил новых настроек.
5. Отмена выбора до готовности стиля теперь очищает отложенную цель камеры до проверки готовности карты. Медленная загрузка не возвращает уже закрытую страну.

Визуальный сценарий проверяет конечный центр и масштаб Франции после быстрой отметки. Переход 4,8 → 6,2 сохранил тот же canvas и дал 148/154 промежуточных render-события между zoom 5 и 6. Это проверка непрерывности перехода, не измерение FPS.

## Артефакты и повторение

Скрипт `scripts/verify-live-map.mjs` заново создаёт в `artifacts/ui-redesign/` по семь снимков для desktop и mobile: `globe-empty`, `search`, `france`, `mercator`, `place-editor`, `collection`, `globe-returning`, а также `live-result.json`. Во время приёмки снимки были просмотрены; мобильные France/Mercator пересняты после исправления перелёта. Тестовые поездки создаются в отдельных контекстах браузера, приложение поставляется с пустой коллекцией.

Запуск: `npm run build`, затем `npm run preview -- --port 4173 --strictPort`. В другом терминале — `node scripts/verify-live-map.mjs`. Для production E2E задайте `$env:TRAVEL_E2E_BASE_URL='http://127.0.0.1:4173'` и выполните `npm run test:e2e`. Обычный E2E без этой переменной сам запускает Vite.

Устаревшие задания, отчёты и архивы тестов прежнего интерфейса удалены. Актуальные тесты и скрипты воспроизведения проверок сохранены.
